## 💫 Core Features

- 🛸 **Cyberpunk Aesthetic:** Sleek dark-mode grid background, neon glowing elements, scanline overlays, and responsive animations.
- ⚡ **Interactive Background Systems:** Custom particle interactions, glowing lines, and dynamic network-mesh effects.
- 🎯 **Framer Motion Micro-Animations:** Fluid scroll progress bars, custom entry/exit transitions, and clean typography effects.
- 🧲 **Magnetic Effect Hook:** Physical "magnetic pull" animations on buttons and social icons on hover for elevated tactile UX.
- 🌓 **Dynamic Theme Integration:** Theme context allowing seamless transition between palettes (Cyberpunk-Dark and Tech-Light).
- 🛠️ **Fully Responsive:** Custom mobile navigation drawer, fluid grid systems, and adaptive components for all screens.

## 🚀 Local Installation & Setup

Follow these simple steps to spin up the developer portfolio locally:

### 1. Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### 2. Clone the Repository
```bash
git clone https://github.com/Tirth2004-git/MERN_Protfolie.git
cd MERN_Protfolie
```

### 3. Install Dependencies
Using npm:
```bash
npm install
```

### 4. Launch the Dev Server
Run the development command to launch the live hot-reload server:
```bash
npm run dev
```
Open your browser to `http://localhost:5173` (or the port specified in terminal) to view the application.

### 5. Build for Production
To bundle the project and optimize assets for deployment:
```bash
npm run build
```
The output directory will be `dist/`, which is ready to host on platforms like Vercel, Netlify, or GitHub Pages.
